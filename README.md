# simbad-prebid-ios-sdk

This is repacked Prebid Mobile iOS SDK with fixed core files for Simb-AD.com

################### INSTALLATION ###################

❌ Remove Prebid Mobile iOS SDK from Package Dependencies first, if you used it before.

🢃 Get and unpack prebid-mobile-ios-sdk-fixed.zip and unarchive whereever you want.

✊ Drag the unpacked folder and drop it to the Project Navigator.

💾 Go to your project's Target settins (General -> Frameworks, Libraries, and Embedded Content), click '+' and choose local PrebidMobile.

😎 C'est fin!
